# Job status gateway contract v1

## Purpose

SAX-041 adds the product-facing read boundary for an existing transcription job.

```text
Next.js
→ Spring Boot product API
→ existing Python/FastAPI AI service
```

FastAPI remains authoritative. Spring does not persist, reconstruct, transition, or calculate job data.

## Public request

```http
GET /api/v1/transcriptions/{job_id}
Accept: application/json
```

`job_id` must be a UUID. The exact UUID is forwarded without transformation to:

```http
GET {SAXO_AI_BASE_URL}/api/v1/transcriptions/{job_id}
```

No multipart body, request body, audio, retry, polling, or replacement identifier is generated by the Backend.

## Successful response

Only FastAPI HTTP 200 is accepted. Spring returns HTTP 200 and preserves exactly:

```json
{
  "job_id": "11111111-1111-1111-1111-111111111111",
  "status": "UPLOADED",
  "filename": "recording.wav",
  "size_bytes": 12345,
  "audio_sha256": "64 lowercase hexadecimal characters",
  "saxophone_type": "alto",
  "input_mode": "solo"
}
```

The client validates UUID syntax and equality with the requested UUID, nonblank status, safe basename, nonnegative size, lowercase SHA-256, known saxophone type, and known input mode. It does not calculate another digest.

The AI contract currently defines only `UPLOADED` and `FAILED`. The Backend preserves the status string and does not invent transitions.

## Public errors

Envelope:

```json
{
  "code": "TRANSCRIPTION_NOT_FOUND",
  "message": "Transcription job not found.",
  "field": "job_id"
}
```

Mapping:

| Condition | HTTP | Code |
| --- | ---: | --- |
| malformed route UUID | 400 | `INVALID_JOB_ID` |
| FastAPI 422 for the identifier | 400 | `INVALID_JOB_ID` |
| FastAPI 404 | 404 | `TRANSCRIPTION_NOT_FOUND` |
| timeout or connection refusal | 502 | `AI_SERVICE_UNAVAILABLE` |
| FastAPI 5xx or unexpected status | 502 | `AI_SERVICE_ERROR` |
| malformed or incompatible HTTP 200 JSON | 502 | `AI_SERVICE_ERROR` |

Raw FastAPI bodies, HTML, internal URLs, hostnames, stack traces, audio, and client paths are never exposed.

## Architecture

```text
web/TranscriptionStatusController
→ application/GetTranscription
→ application/TranscriptionGateway.get(UUID)
→ infrastructure/ai/FastApiTranscriptionClient
```

Application and domain contain no Spring HTTP dependency. Infrastructure owns the internal HTTP request and response validation. Web owns route parsing and the public envelope.

## CORS

The configured `SAXO_FRONTEND_ORIGIN` may use POST, GET, and OPTIONS on `/api/v1/transcriptions/**`. Credentials remain disabled and wildcard origins are not allowed.

## Storage and lifecycle

The Backend has no job repository, database, filesystem record, cache, object storage, or retention behavior. Every GET reaches FastAPI once. SAX-041 does not execute a model or change a status.

## Scope exclusions

No SAX-042, notes, confidence markers, timeline, score viewer, downloads, authentication, persistence, queue, worker, percentage, ETA, WebSocket, SSE, or long polling is implemented.
